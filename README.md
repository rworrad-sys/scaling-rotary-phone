# Resume Polish AI

One-page $50 resume polish product site.

## Deploy

Use this repo with Cloudflare Pages or Vercel.

### Cloudflare Pages
- Framework preset: None
- Build command: leave blank
- Build output directory: /
- Custom domain: resume.mydigitalprompt.com

### Required edits
Replace in index.html:
- YOUR_SQUARE_PAYMENT_LINK_HERE with your Square $50 payment link
- YOUR_EMAIL_HERE with your intake email

## Product
$50 career package including resume polish, ATS review, cover letter, LinkedIn profile wording, and job-targeting direction.
